# 🔍 HydraLOG v1.2.4

## OSINT Information Gathering Tool

HydraLOG is a tool for gathering public information from IP addresses and phone numbers.

---

## 👤 Author

**znyvx**

---

## 📋 What it does

- IP address geolocation (country, city, coordinates)
- ISP / provider information
- Phone number validation and carrier info
- Timezone detection
- Map links (Google Maps, OpenStreetMap)

---

## 📦 Installation & Usage

### 🐧 Linux / 🍎 macOS / 📱 Termux (Android)
pkg update && pkg upgrade

# Clone repository
git clone https://github.com/znyvx/HydraLOG.git

# Enter directory
cd HydraLOG

# Install requirements
pip install -r requirements.txt

# Run tool
python hydralog.py
How to use:
Run python hydralog.py

Choose option from menu:

[1] – IP Information

[2] – Phone Number Information

[0] – Exit

Enter IP address or phone number

View results (location, ISP, coordinates, map links)
